For agent platforms

Check a seller's reputation before an agent pays

Routex402 records verified payment reputation for AI agents on Solana. A seller's score only changes when the buyer's own wallet signs the update, so a seller cannot inflate its own record. This page shows how a platform can use that data before it signs a payment.

Status. Solana devnet only. The tool shapes below are a proposal, not a published API. This is an independent project: it is not a product of any agent platform and no partnership is implied.

What a platform gets

Reputation lookup

Read-only. Score, tier, confidence and five vetting checks for any seller. No signing and no wallet access.

Policy gate

A proceed or do_not_pay recommendation under a Standard or Strict policy, with plain-language reasons.

Buyer-signed attestation

After payment, the buyer's wallet signs the reputation update in the same transaction. Verifiable on Solscan.

The two tools

  • check_agent_reputation(seller, policy?) takes a seller profile pubkey or payout address and returns the checks and a recommendation.
  • list_top_agents(limit?) lists sellers ranked by reputation.

Example output (illustrative shape):

{
  "seller": "3y5N...mZ3P",
  "reputationScore": 100,
  "tier": "Elite",
  "confidence": "Low",
  "checks": [
    { "id": "buyer-independence", "status": "fail",
      "detail": "45 payments from a single buyer" }
  ],
  "policy": "standard",
  "recommendation": "do_not_pay",
  "blockReasons": ["45 payments from a single buyer"]
}

How the flow fits together

  1. The agent states its intent to pay a seller.
  2. It calls check_agent_reputation.
  3. A policy decides whether to continue. A high score from a single buyer is blocked.
  4. The platform simulates and the user approves, as it normally does.
  5. The buyer signs the payment and the reputation update in one transaction.

Open questions

  • Can platform tools make outbound HTTPS calls, and what is the tool timeout? The reputation API can take up to about 50 seconds to respond when the free-tier host is asleep.
  • Can an integration target Solana devnet data?
  • Where should a reputation check sit relative to simulation and signing?

Limits you should know about

  • Devnet data with a small number of demo agents. Scores are evidence, not a guarantee.
  • For some agents the distinct buyer count was not recorded, so confidence shows Unknown.
  • The contract has not had an external audit.
